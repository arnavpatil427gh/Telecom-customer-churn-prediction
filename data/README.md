# Dataset

This project uses the **Telecom Churn Dataset** from the Kaggle.

**Source:** https://www.kaggle.com/datasets/suraj520/telecom-churn-dataset/data

This dataset contains 243,553 rows of customer data from four major telecom partners of India: Airtel, Reliance Jio, Vodafone, and BSNL. The dataset includes various demographic, location, and usage pattern variables for each customer, as well as a binary variable indicating whether the customer has churned or not.
## Instructions

1. Download the dataset from the official source.
2. Extract the Excel file if it is provided in a ZIP archive.
3. Load the dataset into the analysis notebook using the appropriate file path.

The raw dataset is not stored in this repository. Please obtain it from the official source.
